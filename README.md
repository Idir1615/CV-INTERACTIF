# 📄 CV interactif : Idir Sehrane

CV en ligne et interactif d'**Idir Sehrane**, étudiant en BTS SIO option SLAM.

## 📌 Contenu

- Présentation avec titre animé (effet machine à écrire)
- Compétences en développement
- Projets réalisés
- Formation et expériences professionnelles
- Veilles technologiques (ex. GPU / DLSS)
- Loisirs et coordonnées
- Documents téléchargeables dans `PDF/` : CV, certifications, attestation PIX, tableau de synthèse E5, veilles

## 🛠️ Technologies

HTML5 · CSS3 · JavaScript · Bootstrap

## 🚀 Lancer le projet

Aucune installation n'est nécessaire : il suffit d'ouvrir `index.html` dans un navigateur.
Le site peut aussi être publié avec **GitHub Pages** (*Settings → Pages → branche `Realease1`*).

> ℹ️ La version la plus récente du portfolio se trouve dans le dépôt [MonPortfolio](https://github.com/Idir1615/MonPortfolio).
